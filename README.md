# BioVault
## Overview
BioVault is a secure biometric authentication system designed to safeguard sensitive biometric data such as fingerprints. Unlike traditional centralized biometric systems that risk privacy leaks if a server is compromised, BioVault introduces a distributed and privacy-preserving architecture. It segments biometric templates and stores them across randomly chosen distributed servers, ensuring that even if one server is breached, the complete biometric identity cannot be reconstructed.
